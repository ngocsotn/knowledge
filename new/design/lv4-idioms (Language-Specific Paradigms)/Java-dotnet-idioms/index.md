# Java & .NET Idioms

## Topics

- Properties / Getters and Setters: Wrapping class variables inside public methods to protect internal state encapsulation.
- Dispose Pattern (IDisposable / try-with-resources): Forcing developers to cleanly close and release unmanaged system resources (like database connections or files) as soon as they are done.
- LINQ (Language Integrated Query in C#): Writing database-like queries directly into the language syntax to filter and map local data collections.
