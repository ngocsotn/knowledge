# JS TS Idioms

## Topics

- IIFE (Immediately Invoked Function Expression): Running a JavaScript function immediately as soon as it is defined to prevent polluting global scopes.
- Closures: A function that "remembers" its outer lexical environment variables even after the outer function has finished executing.
- Currying: Transforming a function that takes multiple arguments into a sequence of nested functions that take one argument each (e.g., f(a, b, c) into f(a)(b)(c)).
